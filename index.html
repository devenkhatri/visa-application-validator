The Challenge

The current process
is broken

Visa consultancies today rely on manual document review — a slow, inconsistent, and error-prone process that limits how many applications can be handled and increases the risk of avoidable rejections.

⏱️
Speed
Hours per application
Consultants manually check every document against each country's requirements. A single application review takes 2–4 hours. At scale, this becomes a bottleneck that limits business growth.
⚖️
Consistency
Human error and inconsistency
Different consultants apply different standards. Junior staff may miss requirements. Checklists fall out of date. The quality of a review depends on who is doing it on that day.
📉
Outcome
Avoidable rejections
Applicants submit with missing or weak documents that a thorough review would have caught. Rejections damage the consultancy's reputation and require costly reapplication processes.
The Solution

How the system
works — step by step

A five-step AI pipeline processes every visa application automatically. Each step is designed for accuracy, privacy, and speed — delivering a complete review in under 3 minutes.

1
Document Intake
Applicant uploads their documents
The applicant or agent uploads visa documents through the web portal — passport scans, bank statements, employment letters, photographs, and supporting documents. Files are accepted as PDF, JPG, or PNG. Each file is immediately fingerprinted using an MD5 hash for the caching system, then stored securely in the client's own Google Drive or OneDrive account. The application never touches our servers' permanent storage.
📂 Google Drive API ☁️ OneDrive API 🔐 AES-256 Encryption 🔍 MD5 Fingerprinting
2
OCR Extraction with Smart Caching
Mistral AI reads and extracts document data
Before calling the OCR model, the system checks a database cache using the document's MD5 hash. If this exact document has been processed before, the stored extraction is returned instantly at zero cost. On a cache miss, Mistral Small 3.1 — hosted in the EU for GDPR compliance — reads the document and extracts structured data: document type, field values, expiry dates, validity status, and a confidence score. The extraction is then stored in the cache for 90 days. This OCR cache is one of the most important cost and performance optimisations in the system — resubmissions and partial updates reuse the cache automatically.
🤖 Mistral Small 3.1 🇪🇺 EU Endpoint ⚡ OCR Cache (90 days) 💰 Cache = ~₹0 per hit
3
Privacy Protection
PII Scrubber removes all sensitive identifiers
Before any data is sent to Claude for analysis, it passes through the PII Scrubber — a critical data transformation layer. This converts every sensitive field into an anonymised summary. Passport numbers become has_passport_number: true. Exact bank balances become financial_range: "medium". Full names, account numbers, dates of birth, and exact salary figures are all removed or converted to banded ranges. Claude never sees a single real personal identifier. This is not just good practice — it is the core of the system's data privacy architecture and simplifies GDPR compliance significantly.
🛡️ scrubPII() function 🚫 No raw PII to AI 📊 Banded ranges only ✅ GDPR simplified
4
AI Gap Analysis
Claude analyses the application against the visa checklist
Claude Sonnet 4.6 — one of the most capable AI models for structured document reasoning — receives the scrubbed summaries alongside the complete country-specific visa checklist. It acts as an expert visa officer, evaluating each requirement against what has been submitted. Claude returns a fully structured JSON response: a gap analysis table with severity ratings and recommendations for each item, an overall probability score from 0 to 100, a breakdown across five weighted components (document completeness 30%, financial strength 25%, travel history 20%, ties to home country 15%, application quality 10%), a verdict (strong / moderate / weak / insufficient), key strengths, critical gaps, and recommended actions. Prompt caching is enabled — the country checklist and system instructions are cached, reducing per-application AI cost by up to 90%.
🧠 Claude Sonnet 4.6 📋 Country checklist matching 💡 Prompt caching (90% saving) 📊 5-component score
5
Report Delivery
Full report delivered to agent and applicant
The complete gap analysis report is displayed on an interactive dashboard with an animated probability score gauge (colour-coded green / amber / orange / red), a sortable gap analysis table, a bar chart of the five score components, key strengths, critical gaps, and a numbered list of recommended actions. The report is also generated as a downloadable PDF and saved back into the applicant's folder in Google Drive or OneDrive. An email notification is sent to both the agent and the applicant confirming that the review is complete. The entire process from upload to completed report takes under 3 minutes.
📊 Interactive dashboard 📄 PDF download 📧 Email notification ☁️ Saved to Drive/OneDrive
