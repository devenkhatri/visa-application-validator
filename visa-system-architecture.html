03 — Local OCR & Cache Layer
MD5 Fingerprinting · Dual Cache · Local Python OCR Service
?
Generate MD5 hash of document → Check Neon PostgreSQL cache + local SQLite
✓ Hash Found → Instant Return (₹0)
✗ Not Found → Local OCR
⚡
Cache Hit — Zero Cost
Stored extraction returned instantly. Covers resubmissions, partial updates, re-runs. 90-day expiry. Both Neon + SQLite checked.
₹0 per hit
🔒
Cache Miss — Local OCR
Python FastAPI service runs PaddleOCR locally. Document never sent to any cloud API. Result cached for 90 days.
₹0 · 100% Local
PaddleOCR (default)
88–94% accuracy · 2GB RAM · Multilingual passports · No GPU required
Ollama + minicpm-v
90–96% accuracy · 8GB RAM · Structured JSON output · Near-API quality
Tesseract (fallback)
70–85% accuracy · 500MB RAM · Simple docs · No model download
Switch OCR mode: OCR_MODE=local (default, documents stay on machine) or OCR_MODE=mistral (cloud API fallback) — one env var, zero code changes.

07 — Dynamic Personalised Checklist Builder ★ NEW in v1.2
6-Question Profile → Claude Generates Tailored Document List per Applicant
★ Instead of a fixed country template, a 6-question questionnaire builds a personalised document checklist. A self-employed first-time traveller gets completely different requirements than a salaried frequent flyer — the system knows the difference.
Questionnaire → Personalised Checklist Flow
Q1
Employment

Q2
Purpose

Q3
Prior Travel

Intl Travel
Frequent / Occasional / None
Q5
Property
Owns property in home country?
Q6
Balance Range
₹50k / ₹50k–2L / ₹2L–10L / ₹10L+
→ Answers sent to Claude → Personalised checklist returned with score impact per document
🎯
Profile-Aware
Self-employed → ITR required. First-timer → 6 months bank (not 3). Student → sponsorship letter. Each case different.
Not one-size-fits-all
📊
Score Impact Upfront
Each checklist item shows estimated score contribution (+5 to +18 pts). Applicants know which documents matter most before uploading.
Transparent
✏️
Agent Override
Agents can add, remove, or override any checklist item. AI is the starting point — agent has final word. All overrides tracked in agent_overrides JSONB.
Human-in-the-loop
